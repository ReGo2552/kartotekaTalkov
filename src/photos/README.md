# Фото на сайте

## Фото карточек

Фото карточки лежит рядом с её файлом, например:

```
src/content/albums/rossiya.md    ← карточка
src/content/albums/rossiya.jpg   ← обложка
```

В карточке, между строк `---`, фото описано так:

```yaml
photo:
  src: "./rossiya.jpg"
  alt: "Что видно на снимке — для тех, кто не видит картинку"
  caption: "Подпись под фото (можно не писать)"
  credit: "Автор · лицензия"
  url: "Ссылка на страницу, откуда взято фото"
```

**Заменить фото:** положите новый файл с тем же именем поверх старого.
Если у нового файла другое расширение (`.png`, `.webp`), поменяйте его и в `src:`.
Поправьте `credit` и `url`: автора снимка нужно указывать.

**Добавить фото:** положите файл рядом с карточкой и допишите блок `photo:`.
Пока блока нет, на карточке видно пустое место с надписью «Снимка пока нет».

Фото можно класть любого размера: при сборке сайт сам сделает из них
лёгкие версии для телефонов и компьютеров.

## Фото страниц

В этой папке лежат фото, которые стоят прямо на страницах:

| Файл                    | Где                                   |
| ----------------------- | ------------------------------------- |
| `talkov-1991.png`       | главная, большое фото                 |
| `avtograf.png`          | главная, автограф поверх фото         |
| `yubileynyy.jpg`        | «6 октября 1991»                      |
| `mogila.jpg`            | «Память», раздел «Могила»             |
| `marka-1999.jpg`        | «Память», раздел «Марка»              |
| `orig_talkov-1991.jpg`  | оригинал главного фото, на сайт не идёт |

Их тоже можно заменить файлом с тем же именем. Подписи к ним
записаны в самих страницах (`src/pages/…`).
