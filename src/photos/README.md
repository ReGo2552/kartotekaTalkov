# Фото на сайте

## Фото карточек

Фото карточки лежит рядом с её файлом, например:

```
src/content/albums/rossiya.md    ← карточка
src/content/albums/rossiya.jpg   ← обложка
```

В карточке, между строк `---`, фото описано так:

```yaml
photo:
  src: "./rossiya.jpg"
  alt: "Что видно на снимке — для тех, кто не видит картинку"
  caption: "Подпись под фото (можно не писать)"
  credit: "Автор · лицензия"
  url: "Ссылка на страницу, откуда взято фото"
```

**Заменить фото:** положите новый файл с тем же именем поверх старого.
Если у нового файла другое расширение (`.png`, `.webp`), поменяйте его и в `src:`.
Поправьте `credit` и `url`: автора снимка нужно указывать.

**Добавить фото:** положите файл рядом с карточкой и допишите блок `photo:`.
Пока блока нет, на карточке видно пустое место с надписью «Снимка пока нет».

Фото можно класть любого размера: при сборке сайт сам сделает из них
лёгкие версии для телефонов и компьютеров.

## Плёнка

Страница «Плёнка» — 36 кадров, по одному на каждый год жизни, 1956–1991.
Каждый снимок на ней — файл в `src/content/kadry`, например `1991-medvedev.md`:

```yaml
---
year: 1991                 # на кадр какого года встаёт снимок
date: "январь 1991"        # точнее года, если известно (можно не писать)
kind: "снимок"             # снимок, обложка, постер или место
src: "./1991-medvedev.jpg" # файл снимка — рядом или в другой карточке
alt: "Что видно на снимке"
caption: "Подпись на обороте"
credit: "Автор · лицензия"
url: "Ссылка на страницу, откуда взято фото"
see: "albums/rossiya"      # карточка, к которой относится кадр (можно не писать)
best: true                 # обвести кадр красным карандашом (можно не писать)
order: 1                   # порядок, если снимков в году несколько: первый виден на плёнке
---
```

**Добавить снимок:** положите файл в `src/content/kadry` и рядом заведите `.md`
с теми же полями. Кадр этого года проявится сам. Без снимка кадр остаётся тёмным.
